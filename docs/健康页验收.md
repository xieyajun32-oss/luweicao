# 健康页验收 · 2026-11-02

健康页从原始设备条目改为指标和趋势。时间轴只保留原有日记/草稿，不把收件箱或 Oura 数据自动拼成“资料记录”。Oura 数据也不显示在统一收件箱的普通处理列表，原始数据仍支持健康指标和复盘。未执行云端或用户日记删除。

- 睡眠与恢复：准备度、睡眠分数、心率（睡眠平均）、恢复指数贡献分、HRV平衡贡献分、静息心率。移除周期日及占位。静息心率标签不改为其他名称。主睡眠优先于午睡，零值不是缺失。图表对日指标缺口断线，不用0补齐。
- 训练：每日步数趋势、力量训练及网球记录次数/内容/原件。同日同类手动明细优先，避免与Oura重复统计。计划不计入次数。
- 体成分：仅采用已确认来自乐刻的报告；全部已核对指标、体型、节段分析及报告原图。体重kg、体脂率%、骨骼肌kg分别绘图。未知来源需确认；华为不参与趋势。
- 检查：原件、摘要、指标、单位、参考范围、报告明确的要求；不生成虚构复查日期。
- 复盘：每天首次打开健康页、数据更新后按数据指纹生成/读取缓存；云端D1保存且回读。事实由程序计算，AI建议单独标注，并校验来源ID。建议不改写原数据。不是闭站后台定时运行。
- 附件仍取决于R2是否绑定，本机IndexedDB不是云端原件。已收到的个人报告只在项目私人目录整理为导入包，未写入公开源码或仓库；用户导入正式站点后才会进入其私人数据库。

运行验证：node tests/health.test.mjs（Node22及以上）。覆盖空值与零值、主睡眠选择、未来记录排除、来源隔离、训练去重、趋势、复盘回读缓存和引用过滤、停止设备资料日记。浏览器使用标识明确的模拟数据验收桌面和手机布局。真实个人数据与AI输出质量需在已登录的正式站点继续核对。
