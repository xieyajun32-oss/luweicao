# 统一收件箱与健康接通

本版本将“今日记录”入口显示为“统一收件箱”，旧日记、模板及时间轴保留。文字和原件先保存，AI 提出分类和指标，用户核对后归档。领域和时间轴引用同一来源。健康包含六个板块。没有接通外部账号之前，不代表已经完成真实数据同步。

## Cloudflare 生产环境

- 独立 D1 数据库绑定变量名 PRIVATE_DB；建议库名 luweicao-private，不使用港股 hkipo-db。首次请求自动创建 reed_inbox、reed_connections 表。
- 私人 R2 存储桶绑定 PRIVATE_STORE，用于原始附件。没有此绑定时原件仅在当前浏览器 IndexedDB；数据库文字同步不代表原件跨设备可用。R2 若要求开通计费，由用户自行决定。
- Workers AI 绑定 AI，支持文本归档建议和 AI.toMarkdown 文件识别。真实图像提取准确率仍需样本核验。
- OWNER_LOGIN_SECRET 网站密码至少8个字符。
- OURA_CLIENT_ID 应用编号、OURA_CLIENT_SECRET 应用密钥。密钥在 Cloudflare Secret 中填写，不发送到聊天或 GitHub。
- 修改绑定或变量后重新部署。

## Oura 创建应用

Display Name：芦苇草人生复利系统
Description：Personal use only: organize my sleep, activity and workout data.
Contact Email：本人邮箱
Website：https://luweicao.pages.dev/
Privacy Policy：https://luweicao.pages.dev/privacy.html
Terms of Service：https://luweicao.pages.dev/terms.html
Redirect URI：https://luweicao.pages.dev/api/integrations/oura/callback
Scopes：应用设置中启用全部需要读取的权限；网站授权请求不限定 scope，由 Oura 展示全部可用权限。

说明页公开，但不展示私人资料；其他页面和数据接口仍需要密码。回调接口独立核验一次性 state、浏览器 cookie 和 PKCE。授权凭据加密保存到 D1，网站密码或 Oura 密钥更换后需要重新连接。

配置部署完成后，从网站“记忆与设置→连接 Oura”进入官方授权，再选择起始日期并同步全部19类可读数据。当前没有闭站后台定时同步；断开保留历史记录，可在 Oura 账号撤销授权。

## 乐刻和医院资料

通过统一入口发送分享报告、截图、PDF、文本或导出文件，单次最多20份、合计25MB。没有核实到公开个人 API，不承诺乐刻自动抓取。主指标空白不补猜。机器转录与原件分开，用户核对日期、数值、单位后确认。当前趋势板块提供来源与指标回顾，跨来源图表和因果分析尚未实现。

## 范围与验证

新增收件箱使用 D1/R2 同步，旧版日记的整库同步仍沿用原流程，未迁移旧数据。浏览器 JSON 备份不包含 IndexedDB 原件，重要文件需保留独立原件。后端验证覆盖授权加密、回调一次性校验、收件箱版本冲突、缺失指标过滤和全站登录保护；本地预览验证原文保存、回读、归档与健康来源关联。真实 Oura 授权和云端附件保存须配置后再验收。

## 全量读取升级（2026-11-01）

依据 Oura 官方 OpenAPI 1.43 接入全部19类 usercollection 读取端点，不限定返回字段。授权请求省略 scope，按官方规范请求应用可用的全部权限。每类独立请求，逐页续读，没有固定20页上限；心率和戒指电量使用时间参数，按来源日期保存全部采样点。可选择历史起始日期；没有资料或无权访问时单独提示。没有事件日期的个人资料与戒指信息保留为空，不伪造日记日期。官方定义：https://cloud.ouraring.com/v2/static/json/openapi-1.43.json 。
