# 资料入口 · 2026-11-02

唯一提交入口显示名称为“资料入口”，原有书签路由保留兼容。文章、投研等静态页左侧导航使用同一名称。

健康页只展示报告和趋势，不另设上传或资料包导入控件。体测、训练、检查、日记与其他工作生活资料通过同一原件保存及识别流程进入。原件保存并回读后自动尝试识别，建议项目由用户核对后分发。AI失败时保留原件，不声称已提取。

多份非日记附件拆为同批次的独立资料，分别识别日期，避免两年的体测报告合为一个日期；明确的日记配多张照片仍为一条记录。既有原始Oura数据不进入普通资料列表和日记时间轴。

用户决定修改完成后再提交两张乐刻报告，用实际图片继续核对提取、日期、项目关联与趋势。此前生成的私人导入包不再作为操作要求，未导入图片不声称进入网站数据库。照片跨设备保存仍取决于R2原件存储绑定状态。

验证：node tests/material-entry.test.mjs；node tests/health.test.mjs；Hugo构建；本地浏览器检查名称及导航、健康页无第二个上传入口。
